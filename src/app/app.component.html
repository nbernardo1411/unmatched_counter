User Guide

What this app is for

The Unmatched Health App tracks player health for the Unmatched board game. Use it to add characters, monitor life totals, and switch backgrounds for each match.

Basic usage

  1. Select a character from the character selector to add them to the match.
  2. Use the life controls on each character card to increase or decrease health.
  3. Change the background from the background manager to match the table or scenario.
  4. Reset or remove characters as needed during play.

Creating a custom character

To create a custom character, open the character selector and look for the "Add" or "Custom" option. Provide a name, starting health value. After saving, the new character will appear in the selector and can be added to matches like any other character.
